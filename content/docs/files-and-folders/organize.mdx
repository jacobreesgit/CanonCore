---
title: Organize Your Folders
description: Arrange folders with drag and drop
---

CanonCore makes it simple to organize your folders exactly how you want them.

## Enable Edit mode

Before you can drag and drop, enable Edit mode:

1. Click the **Edit** button in the toolbar
2. Folders now show drag handles
3. Click **Done** when finished organizing

Edit mode hides thumbnails and descriptions to keep the interface clean while you rearrange.

## Reorder folders

With Edit mode enabled, drag and drop to reorder:

1. Grab a folder by its drag handle
2. Drag it up or down to the new position
3. Release to drop it in place

The new order is saved automatically.

## Nest folders inside other folders

Create a hierarchy by nesting folders:

1. Click and hold on a folder
2. Drag it over another folder (you'll see it highlight)
3. Drop it to move it inside

The folder becomes a subfolder of the one you dropped it on.

## Move a folder out

To move a subfolder back to the top level:

1. Navigate to the parent folder
2. Drag the subfolder out
3. Or use the breadcrumbs to navigate, then drag to reorder

## Build your hierarchy

With nesting, you can create structures like:

```
Work
├── Projects
│   ├── Project A
│   └── Project B
└── Documents
    ├── Contracts
    └── Reports
```

You can nest folders up to 10 levels deep.

## Tips for organizing

- **Group related items** - Keep similar folders together
- **Use clear names** - Makes it easier to find things later
- **Don't go too deep** - Very deep nesting can be hard to navigate
- **Reorganize as needed** - Your system can evolve over time
