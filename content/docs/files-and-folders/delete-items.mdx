---
title: Delete Items
description: Remove items you no longer need
---

When you don't need an item anymore, you can delete it.

## Delete an item

### Using the context menu

1. Right-click on the item you want to delete
2. Select **Delete** from the menu
3. Confirm that you want to delete it

### Using the header menu

When you're inside an item:

1. Click the three-dot menu (⋮) in the header
2. Select **Delete**
3. Confirm the deletion

## Delete multiple items at once

Need to clean up several items? Use bulk delete:

1. Click **Edit Mode** to enter edit mode
2. Select items by clicking their checkboxes
3. Use the checkbox in the toolbar to toggle all items on/off (optional)
4. Click the **Delete** button showing how many items are selected
5. Confirm the deletion in the dialog

The selection counter shows how many items you've selected.

## Important: What gets deleted

When you delete an item:

- **The item is permanently removed**
- **All child items inside it are also deleted**
- **This action cannot be undone**

Make sure you really want to delete before confirming!

## Before you delete

Consider whether you might:

- Want to [rename](/docs/files-and-folders/item-settings) it instead
- Want to [move it](/docs/files-and-folders/organize) somewhere else
- Need any of the child items inside

## Accidentally deleted something?

Unfortunately, deleted items can't be recovered. In the future, always double-check before confirming a deletion.
