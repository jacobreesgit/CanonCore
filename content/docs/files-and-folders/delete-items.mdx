---
title: Delete Folders
description: Remove folders you no longer need
---

When you don't need a folder anymore, you can delete it.

## Delete a folder

### Using the context menu

1. Right-click on the folder you want to delete
2. Select **Delete** from the menu
3. Confirm that you want to delete it

### Using the header menu

When you're inside a folder:

1. Click the three-dot menu (⋮) in the header
2. Select **Delete**
3. Confirm the deletion

## Important: What gets deleted

When you delete a folder:

- **The folder is permanently removed**
- **All subfolders inside it are also deleted**
- **This action cannot be undone**

Make sure you really want to delete before confirming!

## Before you delete

Consider whether you might:

- Want to [rename](/docs/files-and-folders/rename-items) it instead
- Want to [move it](/docs/files-and-folders/organize) somewhere else
- Need any of the subfolders inside

## Accidentally deleted something?

Unfortunately, deleted folders can't be recovered. In the future, always double-check before confirming a deletion.
