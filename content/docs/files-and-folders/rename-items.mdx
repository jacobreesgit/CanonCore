---
title: Rename Folders
description: Change folder names anytime
---

Changed your mind about a folder name? Renaming is quick and simple.

## Rename a folder

### Using the context menu

1. Right-click on the folder you want to rename
2. Select **Rename** from the menu
3. Type the new name
4. Press **Enter** or click **Rename** to save

### Using the header menu

When you're inside a folder:

1. Click the three-dot menu (⋮) in the header
2. Select **Rename**
3. Type the new name
4. Press **Enter** to save

## Tips for renaming

- The change takes effect immediately
- Renaming a folder doesn't affect its contents
- Subfolders stay where they are
- You can use the same name as another folder (but it's not recommended)

## Cancel a rename

Changed your mind while editing? Press **Escape** to cancel and keep the original name.
