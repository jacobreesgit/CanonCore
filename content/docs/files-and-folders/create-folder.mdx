Folders are the building blocks of your organization system in CanonCore.

## Create a new folder

You have two options to create a folder at the top level:

### Quick Create from the sidebar

The fastest way to add a folder from anywhere in the app:

1. Click the **Quick Create** button in the sidebar
2. Type a name for your folder in the dialog
3. Add an optional description (up to 200 characters)
4. Click **Create** to save

### Add Folder button

When viewing your files:

1. Click the **Add Folder** button (look for the + icon)
2. Type a name for your folder in the dialog
3. Add an optional description
4. Click **Create** or press **Enter** to save

Your new folder appears in the list, ready to use.

## Create a subfolder

Want to nest folders inside other folders? You have two options:

### Option 1: From inside a folder

1. Click on a folder to open it
2. Click **Add Folder**
3. Name your subfolder and save

### Option 2: Using the context menu

1. Right-click on any folder
2. Select **Add Subfolder**
3. Name your subfolder in the dialog and save

## Add a description

The folder creation dialog includes a description field. Use it to:

- Add context about what the folder contains
- Leave notes for yourself
- Describe the folder's purpose

Descriptions are optional and limited to 200 characters. You can add or edit them later in [Item Settings](/docs/files-and-folders/item-settings).

## Naming tips

- Use clear, descriptive names
- Keep names short but meaningful
- You can use letters, numbers, spaces, hyphens, and underscores
- Names don't have to be unique (but it helps!)

## What's next?

Once you've created folders:

- [Configure them](/docs/files-and-folders/item-settings) to add descriptions or rename
- [Organize them](/docs/files-and-folders/organize) by dragging and nesting
- [Delete them](/docs/files-and-folders/delete-items) if you don't need them
