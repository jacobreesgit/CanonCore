Items are the building blocks of your organization system in CanonCore.

## Create a new item

You have two options to create an item at the top level:

### Quick Create from the sidebar

The fastest way to add an item from anywhere in the app:

1. Click the **Quick Create** button in the sidebar
2. Type a name for your item in the dialog
3. Add an optional description (up to 200 characters)
4. Click **Create** to save

### Add Item button

When viewing your items:

1. Click the **Add Item** button (look for the + icon)
2. Type a name for your item in the dialog
3. Add an optional description
4. Click **Create** or press **Enter** to save

Your new item appears in the list, ready to use.

## Create a child item

Want to nest items inside other items? You have two options:

### Option 1: From inside an item

1. Click on an item to open it
2. Click **Add Item**
3. Name your child item and save

### Option 2: Using the context menu

1. Right-click on any item
2. Select **Add Child Item**
3. Name your child item in the dialog and save

## Add a description

The item creation dialog includes a description field. Use it to:

- Add context about what the item contains
- Leave notes for yourself
- Describe the item's purpose

Descriptions are optional and limited to 200 characters. You can add or edit them later in [Item Settings](/docs/files-and-folders/item-settings).

## Naming tips

- Use clear, descriptive names
- Keep names short but meaningful
- You can use letters, numbers, spaces, hyphens, and underscores
- Names don't have to be unique (but it helps!)

## What's next?

Once you've created items:

- [Configure them](/docs/files-and-folders/item-settings) to add descriptions or rename
- [Organize them](/docs/files-and-folders/organize) by dragging and nesting
- [Delete them](/docs/files-and-folders/delete-items) if you don't need them
