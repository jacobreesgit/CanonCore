Items are the building blocks of your organisation system in CanonCore.

## Create a new item

When viewing your items:

1. Click the **Add Item** button in the toolbar (look for the + icon)
2. Type a name for your item in the dialogue
3. Add an optional description (up to 1000 characters)
4. Click **Create** or press **Enter** to save

Your new item appears in the list, ready to use.

## Using the name field

The name field doubles as a search box for The Movie Database (TMDB). As you type, it looks for matching movies and TV shows.

### For movies and TV shows

1. Start typing a movie or TV show name
2. Results appear with poster thumbnails and release years
3. Click a result to open the metadata wizard
4. Choose which fields to update (name, description)
5. Click **Apply** to use the selected metadata

**For TV shows**, you can drill down to a specific level:

- **Use Entire Show** - Apply show-level metadata
- **Select a Season** - Use season-level metadata
- **Select an Episode** - Use episode-level metadata (skips artwork steps since episodes have no TMDB artwork)

The wizard also lets you pick poster and hero images, though for new items you'll want to [connect Google Drive](/docs/google-drive/connect-drive) first so the images have somewhere to upload.

## Upload files during creation

You can attach files when creating an item instead of adding them later. The dialogue has two tabs:

- **Details** - Name and description fields with TMDB search
- **Files** - Dropzones for uploading different file types

The Files tab has four dropzones:

- **Primary Media** - Videos and audio files for playback
- **Primary Artwork** - Poster images for thumbnails
- **Hero Image** - Landscape images for the banner background
- **Default Subtitle** - SRT, VTT, or ASS subtitle files

To add files:

1. Click the **Files** tab
2. Find the dropzone for your file type
3. Drag files onto the dropzone or click to browse
4. Files queue until you click **Create**
5. Once created, files upload automatically to Google Drive

The first file in each category becomes the primary (for media) or default (for subtitles). You can change this later in [Item Settings](/docs/files-and-folders/item-settings).

**Note:** You need to [connect Google Drive](/docs/google-drive/connect-drive) before uploading files. Without a connection, the upload tabs won't appear.

### For other content

Creating a folder, game, book, or anything else? Just type the name and ignore the search results:

1. Type your item name
2. If TMDB results appear, ignore them
3. Click **Create** to save with your typed name

The search runs automatically but you're never required to use it. Whatever text is in the name field becomes your item name.

### When TMDB has no results

If you search for something TMDB doesn't recognise, you'll see "No results found". This is fine - just keep typing your name and click **Create**. The item saves with exactly what you typed.

## Create a child item

Want to nest items inside other items? You have two options:

### Option 1: From inside an item

1. Click on an item to open it
2. Click **Add Item**
3. Name your child item and save

### Option 2: Using the context menu

1. Right-click on any item
2. Select **Add Child Item**
3. Name your child item in the dialogue and save

## Add a description

The item creation dialogue includes a description field. Use it to:

- Add context about what the item contains
- Leave notes for yourself
- Describe the item's purpose

Descriptions are optional and limited to 1000 characters. You can add or edit them later in [Item Settings](/docs/files-and-folders/item-settings).

## Naming tips

- Use clear, descriptive names
- Keep names short but meaningful
- You can use letters, numbers, spaces, hyphens, and underscores
- Names don't have to be unique (but it helps!)

## What's next?

Once you've created items:

- [Configure them](/docs/files-and-folders/item-settings) to add descriptions or rename
- [Organise them](/docs/files-and-folders/organise) by dragging and nesting
- [Delete them](/docs/files-and-folders/delete-items) if you don't need them
