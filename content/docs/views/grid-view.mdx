title: Grid View
description: See your folders as visual cards
---

Grid view displays your folders as cards in a grid layout, making it easy to scan and find what you need.

## What grid view looks like

Your folders appear as individual cards arranged in a grid. Each card shows:

- The folder icon
- The folder name

Cards are arranged in rows and wrap automatically based on your screen size.

## Switch to grid view

1. Look for the view toggle in the top-right of your folder list
2. Click the grid icon to switch to grid view

## Working in grid view

### Open a folder

Click on any folder card to navigate inside it.

### Drag and drop

- Drag cards to rearrange them at the same level

### Right-click for options

Right-click any card to see options like rename and delete.

## When to use grid view

Grid view works best when:

- You prefer a visual, spacious layout
- You're browsing and scanning for a folder
- You have fewer folders to display
- You find cards easier to read than lists

## Prefer a compact list?

Try [tree view](/docs/views/tree-view) for a hierarchical list layout that shows nested folders all at once.

## Your preference is remembered

CanonCore remembers which view you prefer and uses it each time you visit.
