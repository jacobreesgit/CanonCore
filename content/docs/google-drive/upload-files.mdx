## Upload files to items

You can upload media, artwork, and subtitles directly from CanonCore to your Google Drive.

1. Open an item by clicking on it
2. Open the **Settings** dialogue (right-click → Settings, or click the settings icon)
3. Find the file type you want to upload (Media, Artwork, or Subtitles)
4. Click **Upload** next to that section
5. Select files from your computer
6. Watch the upload progress

Files upload directly to Google Drive and sync to CanonCore automatically.

## Upload progress

During upload, you'll see:

- File name and size
- Progress bar showing upload percentage
- Bytes uploaded / total bytes

You can upload multiple files at once. They upload in parallel for faster completion.

## Supported file types

**Media files:**

- Video: MP4, MKV, AVI, M4V, WebM, MOV
- Audio: MP3, M4A, FLAC, WAV, OGG

**Artwork:**

- Images: JPG, PNG, GIF, WebP

**Subtitles:**

- SRT, VTT, SUB, ASS

## Storage limits

CanonCore checks your Google Drive storage before starting an upload. If your Drive is 95% full or more, the upload is blocked before it begins. You'll see an error asking you to free up space or upgrade your Google Drive plan.

Check your storage usage in **Settings** under the Google Drive section. The storage bar shows how much of your quota is in use.

## Cancel an upload

Click the cancel button during upload to stop it. Partially uploaded files are cleaned up automatically.

## Create items with uploads

When you create a new item, it becomes a folder in Google Drive. You can then upload files to that item, and they'll appear in the corresponding Drive folder.

## Rename and delete files

To manage existing files:

1. Open the item's **Settings** dialogue
2. Find the file you want to manage
3. Use the context menu or buttons to rename or delete

Deletions move files to Google Drive's trash, so you can recover them if needed.

## Choose primary files

When an item has multiple media files, you can set which one plays by default:

1. Open **Settings** for the item
2. Find the **Primary Media** dropdown
3. Select the file you want as primary

The primary file plays when you click **Play** from the item detail view.
