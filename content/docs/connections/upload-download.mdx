---
title: Download and Manage Files
description: Download files and organize your remote folders
---

## Download files

To download a file from your SFTP server:

1. Open your connection and navigate to a folder
2. Click on the folder to open its detail view
3. Find the file you want in the Media, Artwork, or Subtitles section
4. Click the download icon next to the file

The file downloads to your browser's default download location.

## Create folders on the server

You can create new folders directly on your SFTP server:

1. Navigate to where you want the folder
2. Click the **Add** button
3. Enter a folder name
4. Press Enter or click away to confirm

The folder appears both in CanonCore and on your server.

## Rename items

To rename a folder:

1. Right-click the folder to open the context menu
2. Select **Rename**
3. Enter the new name
4. Press Enter to confirm

The rename happens on your SFTP server, so the change persists.

## Delete items

To delete a folder:

1. Right-click the folder
2. Select **Delete**
3. Confirm the deletion

Deleting removes the item from both CanonCore and your SFTP server. Be careful - this can't be undone.

## Organizing with drag and drop

You can reorganize folders by dragging them:

1. Click and hold a folder
2. Drag it to a new position
3. Drop to reorder

This changes the display order in CanonCore. The actual folder structure on your server stays the same.
