title: Upload and Download Files
description: Transfer files to and from your SFTP server
---

## Download files

To download a file from your SFTP server:

1. Open your connection
2. Navigate to the file you want
3. Hover over the file to reveal the download button
4. Click the download icon

The file downloads to your browser's default download location.

## Upload files

To upload files to your SFTP server:

1. Open your connection
2. Navigate to where you want the file
3. Click the **Upload** button in the toolbar
4. Select one or more files from your computer
5. Click **Upload**

Uploaded files appear after the transfer completes. For large files, you'll see a progress indicator.

## Create folders on the server

You can create new folders directly on your SFTP server:

1. Click the **Add** button
2. Enter a folder name
3. Press Enter or click Create

The folder appears both in CanonCore and on your server.

## Rename and delete on the server

Changes you make in CanonCore sync back to your server:

- **Rename** - Right-click an item, choose Rename, enter the new name
- **Delete** - Right-click an item, choose Delete, confirm

These changes happen on your actual SFTP server, so be careful with delete operations.

## File size limits

Most SFTP servers handle files of any size, but very large files (over 1GB) may take a while to transfer. The upload progress indicator shows how far along you are.

## Supported file types

CanonCore works with any file type your SFTP server accepts. Common uses include:

- Documents and PDFs
- Images and media files
- Configuration files
- Backups and archives
