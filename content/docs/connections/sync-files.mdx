## How syncing works

When you sync, CanonCore compares files between your server and the web interface. New files appear, deleted files disappear, and everything stays up to date.

## Start a sync

1. Click on your connection to open it
2. Click the **Sync** button in the toolbar
3. Wait for the sync to complete

The button changes from "Sync" to "Syncing..." to "Synced" as it progresses.

## What gets synced

- **New folders and files** on your server appear in the web interface
- **Deleted items** on your server are removed from the web view
- **Renamed items** update to match the server

## Sync status badges

Look for colored badges on your files:

| Badge                | Meaning                      |
| -------------------- | ---------------------------- |
| Green "Synced"       | File matches the server      |
| Blue "Uploading"     | File is being sent to server |
| Purple "Downloading" | File is coming from server   |
| Yellow "Conflict"    | Different versions exist     |
| Red "Error"          | Something went wrong         |

Hover over any item to see its sync status.

## Automatic vs manual sync

Currently, syncing is manual - you click the button when you want to update. This gives you control over when transfers happen, especially useful on slower connections.

## Troubleshooting

**Sync seems stuck?** Check your internet connection and try again. Large folders take longer.

**Files missing?** Make sure you're looking in the right folder. Use the breadcrumb navigation to go up levels.

**Error badges appearing?** Click the sync button again. Temporary network issues usually resolve on retry.
