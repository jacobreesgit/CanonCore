---
title: Manage Remote Items
description: Download files and organize your remote items
---

## Download files

To download a file from your SFTP server:

1. Open your connection and navigate to an item
2. Click on the item to open its detail view
3. Find the file you want in the Media, Artwork, or Subtitles section
4. Click the download icon next to the file

The file downloads to your browser's default download location.

## Create items on the server

You can create new items directly on your SFTP server:

1. Navigate to where you want the item
2. Click the **Add Item** button
3. Enter an item name in the dialog
4. Optionally add a description
5. Click **Create** to confirm

The item appears both in CanonCore and on your server.

## Rename items

To rename an item:

1. Right-click the item to open the context menu
2. Select **Settings**
3. Update the name and click **Save**

The rename happens on your SFTP server, so the change persists.

## Delete items

To delete an item:

1. Right-click the item
2. Select **Delete**
3. Confirm the deletion

Deleting removes the item from both CanonCore and your SFTP server. Be careful - this can't be undone.

## Organizing with drag and drop

You can reorganize items by dragging them:

1. Click **Edit** to enter edit mode
2. Grab an item by its drag handle
3. Drag it to a new position
4. Drop to reorder
5. Click **Done** when finished

This changes the display order in CanonCore. The actual structure on your server stays the same.
