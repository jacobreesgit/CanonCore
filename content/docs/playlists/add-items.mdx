---
title: Add and Arrange Items
description: Add items to playlists and reorder them with drag and drop
---

Once you've created a playlist, you can add items from anywhere in your library. Each item can belong to multiple playlists at once.

## Add items to a playlist

### From an item detail page

1. Open any item's detail page
2. Click **Add to Playlist** in the hero section
3. A dialogue shows all your playlists with checkboxes
4. Tick a playlist to add the item, or untick to remove it — changes save instantly

You can also create a new playlist directly from this dialogue if you don't have one yet.

### From the context menu

You can also add items to playlists straight from the grid — no need to open the item first.

1. Right-click any item (your own items on your profile, or any item on the Explore page)
2. Select **Add to Playlist**
3. Choose which playlists to add it to

This works on your own items and on other people's public items you discover whilst browsing.

## Remove items from a playlist

1. Open the playlist detail page
2. Right-click the item you want to remove
3. Select **Remove from Playlist**

Removing an item from a playlist doesn't delete it from your library — it only removes the reference.

## Reorder items

Playlists support drag-to-reorder so you can arrange items in any order you like.

1. Open the playlist detail page
2. Switch to **Edit** mode using the toggle in the toolbar
3. Drag items by their handle to rearrange
4. The new order saves automatically

Edit mode is only available when the sort is set to **Custom Order**.

## View playlist contents

Open any playlist to see its items displayed in a grid. The playlist detail page has two tabs:

- **Contents** — the items in the playlist, shown in your chosen order
- **About** — playlist description and metadata
