---
title: Share Playlists
description: Control who can see your playlists and share them with others
---

Playlists can be private, public, or shared via a link. You control visibility when editing a playlist.

## Visibility options

### Private

Only you can see the playlist. It won't appear on your public profile or the Explore page. This is the default when creating a playlist.

### Public

Anyone can discover and view the playlist. Public playlists appear:

- On your profile page under the **Playlists** tab
- On the **Explore** page under the **Playlists** tab
- In Spotlight Search results

Toggle the **Public** switch in the edit dialogue to make a playlist public or private.

### Shared via link

For private playlists, you can generate a shareable link so specific people can view them. Anyone with the link can view the playlist, even without a CanonCore account. Link-shared playlists don't appear on the Explore page or in search results.

The shareable link option is only available when a playlist is set to private. Public playlists are already accessible to everyone, so they don't need a share link.

## Share a playlist via link

1. Open the playlist detail page and click **Edit**
2. Make sure the playlist is set to private (the **Public** toggle is off)
3. In the **Shareable link** section, enable the sharing toggle
4. Copy the link using the copy button

The link contains a unique token. Share it with anyone you'd like to give access.

## Regenerate a share link

If you want to invalidate an existing link:

1. Open the **Edit** dialogue for the playlist
2. In the **Shareable link** section, click the regenerate button (the refresh icon)
3. The old link stops working immediately
4. Copy the new link to share

## Disable link sharing

1. Open the **Edit** dialogue for the playlist
2. In the **Shareable link** section, toggle sharing off
3. The existing link is removed and stops working

You can re-enable sharing at any time, which generates a new link.

## Discover public playlists

Browse public playlists from other users:

- **Explore page** — select the **Playlists** tab to browse all public playlists
- **Profile pages** — visit someone's profile and select the **Playlists** tab
- **Spotlight Search** — search for playlists by name
