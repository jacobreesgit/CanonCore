# Task 2.1: Accessibility Audit

**Date:** 2026-01-19
**Status:** Completed
**Category:** Web Design Guidelines - Accessibility

## Summary

Audited 24 interactive components against the 10 accessibility rules from the web-design-guidelines. The primary issue found was decorative icons missing `aria-hidden="true"`.

## Rules Applied

1. Icon-only buttons need `aria-label`
2. Form controls need `<label>` or `aria-label`
3. Interactive elements need keyboard handlers
4. Use `<button>` for actions, `<a>`/`<Link>` for navigation
5. Images need `alt` text
6. Decorative icons need `aria-hidden="true"`
7. Async updates need `aria-live="polite"`
8. Prefer semantic HTML over ARIA
9. Headings hierarchical with skip link
10. Heading anchors need `scroll-margin-top`

## Changes Made

Added `aria-hidden="true"` to 35+ decorative icons across 14 component files.

### Pattern Applied

```tsx
// Before
<Settings className="size-4" />

// After
<Settings aria-hidden="true" className="size-4" />
```

This ensures:

- Screen readers skip decorative icons
- Adjacent text labels remain the accessible name
- Icon-only buttons with `aria-label` don't announce redundant icon names
