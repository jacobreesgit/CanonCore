# Task 2.3: Forms Audit

**Date:** 2026-01-19
**Status:** Completed
**Rule Set:** Web Interface Guidelines - Forms (11 Rules)

## Rules Evaluated

1. **Inputs need `autocomplete` and `name`** - Enables browser autofill
2. **Use correct input `type` and `inputmode`** - Mobile keyboard optimization
3. **Never block paste functionality** - Accessibility requirement
4. **Labels must be clickable** - Use `htmlFor` pointing to input `id`
5. **Disable spellcheck on emails/codes/usernames** - Prevent red squiggles
6. **Checkboxes/radios share single hit target** - Label wraps input
7. **Submit button stays enabled until request starts** - Better UX
8. **Errors inline next to fields** - Clear error association
9. **Placeholders end with `…` and show pattern** - UX hint
10. **Use `autocomplete="off"` strategically** - For search inputs
11. **Warn before navigation with unsaved changes** - Data loss prevention

## Issues Found & Fixed

### 1. Missing `name` and `autocomplete` Attributes (Rule 1)

All auth pages and settings dialog were missing these critical attributes for browser autofill.

**sign-in/page.tsx:**

- Email input: Added `name="email"`, `autoComplete="email"`
- Password input: Added `name="password"`, `autoComplete="current-password"`

**sign-up/page.tsx:**

- Email input: Added `name="email"`, `autoComplete="email"`
- Username input: Added `name="username"`, `autoComplete="username"`
- Password input: Added `name="new-password"`, `autoComplete="new-password"`
- Confirm password input: Added `name="confirm-password"`, `autoComplete="new-password"`

**forgot-password/page.tsx:**

- Email input: Added `name="email"`, `autoComplete="email"`

**reset-password/page.tsx:**

- New password input: Added `name="new-password"`, `autoComplete="new-password"`
- Confirm password input: Added `name="confirm-password"`, `autoComplete="new-password"`

**settings-dialog.tsx:**

- Name input: Added `name="name"`, `autoComplete="name"`
- Username input: Added `name="username"`, `autoComplete="username"`
- New email input: Added `name="email"`, `autoComplete="email"`
- Current password inputs: Added `name="current-password"`, `autoComplete="current-password"`
- New password inputs: Added `name="new-password"`, `autoComplete="new-password"`
- Confirm password input: Added `name="confirm-password"`, `autoComplete="new-password"`

### 2. Missing `spellCheck={false}` (Rule 5)

Email, username, and password fields should not show spellcheck squiggles.

**Auth pages:**

- Added `spellCheck={false}` to all email inputs

**sign-up/page.tsx:**

- Added `spellCheck={false}` to username input

**settings-dialog.tsx:**

- Added `spellCheck={false}` to email and username inputs

**password-input.tsx:**

- Changed default `spellCheck` from `true` to `false` for all password inputs
- Updated JSDoc to document this behavior
