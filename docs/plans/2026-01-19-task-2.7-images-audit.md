# Task 2.7: Images Audit

## Overview

Audited image loading patterns across the codebase to ensure optimal performance and prevent Cumulative Layout Shift (CLS).

## Rules Audited

1. **`<img>` needs explicit dimensions** - Width/height attributes prevent layout shift
2. **Below-fold images use `loading="lazy"`** - Native browser lazy loading
3. **Above-fold critical images use `priority`** - Eager loading for LCP images

## Pattern Analysis

### Image Loading Strategies in Codebase

1. **`useLazyImage` hook** (`hooks/use-lazy-image.ts`)
   - JavaScript-based lazy loading with Intersection Observer
   - Supports `priority` prop for above-fold images
   - Returns `shouldLoad` to conditionally render images

2. **`useImageLoaded` hook** (`hooks/use-image-loaded.ts`)
   - Tracks image load state for smooth fade-in transitions
   - Handles cached image detection
   - Provides `loaded`, `onLoad`, `onError` for state management

3. **Native `loading` attribute**
   - Browser-native lazy loading hint
   - Works without JavaScript
   - Added as fallback alongside JS solutions

### Recommended Pattern (now implemented)

```tsx
// For grid items with priority support
const { ref, shouldLoad } = useLazyImage({ priority: index < 4 });

{
  shouldLoad && (
    <img
      src={src}
      alt=""
      loading={priority ? "eager" : "lazy"}
      className="..."
    />
  );
}
```
