## Findings

### Rule 1: `color-scheme` Property - ISSUE FOUND

**Location:** `app/globals.css`, `app/layout.tsx`

**Problem:** The `color-scheme` CSS property is not set anywhere. This property tells the browser what color schemes the page supports and affects:

- Native scrollbar styling (scrollbars won't be dark in dark mode)
- Native form controls (date pickers, etc.)
- Visited link colors
- Other browser-native UI elements

**Current state:**

- `app/globals.css:8-48` - `:root` has CSS variables but no `color-scheme`
- `app/globals.css:50-83` - `.dark` has CSS variables but no `color-scheme`
- `components/providers/theme-provider.tsx:18-19` - Uses `attribute="class"` but doesn't enable color scheme

**Fix required:**

1. Add `color-scheme: light` to `:root` in `globals.css`
2. Add `color-scheme: dark` to `.dark` in `globals.css`

---

### Rule 2: `<meta name="theme-color">` - ISSUE FOUND

**Location:** `app/layout.tsx:23-39`

**Problem:** No `theme-color` meta tag exists. The browser UI (address bar on mobile, task switcher) won't match the page background color.

**Current state:**

- `metadata` export includes `icons` but not `themeColor`
- Users on mobile will see default browser chrome colors instead of matching theme colors

**Fix required:**

1. Add `themeColor` to metadata export with light/dark media query support

---

### Rule 3: Native `<select>` Explicit Colors - NOT APPLICABLE

**Location:** `components/ui/select.tsx`

**Analysis:** The shadcn/ui Select component is NOT a native `<select>` element. It uses Radix UI `SelectPrimitive` which renders custom styled elements (`<button>` trigger + portal content).

**Verification:** Searched entire codebase for `<select` - no native select elements found.

**Result:** No action needed - rule does not apply to this codebase.

## Implementation Plan

### Fix 1: Add `color-scheme` to CSS

In `app/globals.css`, add `color-scheme` property:

```css
:root {
  color-scheme: light;
  /* existing variables... */
}

.dark {
  color-scheme: dark;
  /* existing variables... */
}
```

### Fix 2: Add `theme-color` Meta Tag

In `app/layout.tsx`, add `themeColor` to metadata:

```typescript
export const metadata: Metadata = {
  title: "CanonCore",
  description: "CanonCore - Media Library Manager",
  themeColor: [
    { media: "(prefers-color-scheme: light)", color: "#ffffff" },
    { media: "(prefers-color-scheme: dark)", color: "#242424" },
  ],
  // existing icons...
};
```

Note: Colors derived from CSS variables:

- Light `--background: oklch(1 0 0)` = #ffffff
- Dark `--background: oklch(0.145 0 0)` ≈ #242424
